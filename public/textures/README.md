# Textures

This folder is empty on purpose. Facade glass, lit windows, stone, paving,
water ripples, palm fronds and the jaali screen are all drawn at runtime on
an HTML canvas (`lib/three/textures.ts`), so the project ships no texture
files and carries no third-party texture licences.

If you add photographic textures, store them here as KTX2 or WebP at the
smallest resolution that holds up on screen, and record their source and
licence in the main README.
